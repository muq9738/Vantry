Vantry 0.2.5 brings local and paired conversations into the same desktop sidebar and adds clickable image references while composing a message.

- Filter the sidebar by machine, then open a conversation in the same window. Project and conversation actions go to the Core that owns the item. Remote listings use thread summaries until you open a conversation.
- Open the session overview from the upper right to inspect Git changes, delegated tasks and MCP sources. Expand a task to see its output and errors. Searching for a child task leads to its detail from the parent conversation.
- Click an image reference such as `@图1` to preview the attachment before or after sending. The desktop uses NSH 0.7.0 and enables rich editing for drafts containing references.
- Markdown tables give long descriptions more room and wrap text within each column. Charts fit the message width and accept standard Markdown tables with leading and trailing pipes.
- Paired connections on macOS now use socket paths that fit the operating system limit. Sidebar row actions have dedicated space when hovering over long conversation titles.
