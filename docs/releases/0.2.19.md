# Vantry 0.2.19

- Choose a configured model in a shared local conversation in Alma iOS. Tap the model name in the conversation header. Vantry saves the selection on that thread, uses it for the next message, and restores it when the phone reconnects.
- Connect a dedicated writing thread to a host-configured Gemini web adapter. The phone can follow a request through a disconnect and receive the completed reply in the original message. Recovery reopens the same web turn without submitting the prompt again.
- A writing adapter can return a Drive link for an archived manuscript. Synthetic test threads can display the full reply in Alma.
