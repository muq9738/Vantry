# Vantry 0.2.10

- Clicking "Restart to Update" on macOS now passes the desktop PID, terminates peer-proxy tunnels, and quits the app cleanly so `apply-update` installs the staged bundle and reopens Vantry automatically.
- In-app restarts no longer interrupt running local or remote tasks: an idle local Core drains and upgrades immediately, while a busy local Core and its active workers stay untouched until the next launch.
- Update actions in Settings always target the local desktop installation even while viewing a paired remote machine, keep staged updates intact if a restart attempt fails, and clearly report when the desktop is already updated ahead of a busy local Core.
- Desktop updates from 0.2.9 can use verified delta downloads on macOS arm64 and Windows x64.
