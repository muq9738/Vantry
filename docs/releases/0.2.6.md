Vantry 0.2.6 fixes a regression in 0.2.5 that could leave the desktop running without a visible workbench.

- Opening Vantry shows the workbench. On macOS, clicking the Dock icon brings it forward, restores it when minimized, or opens a new window after the last one closes.
- The sidebar, title bar spacing, and tool panels now follow the size of the visible workbench as you resize it.

## Downloads

- **Apple Silicon Macs running macOS 14 or later** — Open the disk image and drag Vantry into Applications. [Download the macOS disk image](https://github.com/muq9738/Vantry/releases/download/v0.2.6/Vantry-0.2.6-macos-arm64.dmg)
- **Windows x64** — Extract the portable ZIP and open `Vantry.exe`. [Download the Windows desktop ZIP](https://github.com/muq9738/Vantry/releases/download/v0.2.6/vantry-0.2.6-windows-amd64.zip)
