# Vantry 0.2.12

- Type into and resize interactive sessions in the built-in terminal. Output that arrives before the panel opens is shown when it mounts. The terminal and cursor follow the app theme, and the panel shows an empty state when no session is open.
- Keep the Send button in view when the composer gets narrow, such as when the tools dock is open. Toolbar labels and model names take up less space, and a single control switches between inserting a message now and sending it on the next turn.
- Paste text and images together without losing the text. Copying a message puts all its images on the clipboard, and pasting it back into the composer restores them at the original `@图N` references. Sent messages show images above the text, and image-reference highlights follow your selected theme.
- Click the machine or directory below the composer to start a conversation on another machine or browse folders on the current one, including paired hosts. Use the arrow keys to select, Enter to open a folder, ⌘Enter to use it, Backspace to go up, and Esc to close. Start the filter with a dot to show hidden folders, or use the system folder picker on your Mac.
