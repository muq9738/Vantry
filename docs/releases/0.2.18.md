# Vantry 0.2.18

- Open a saved Vantry conversation in Alma iOS. Choose **Open with Alma iOS** from the conversation menu and scan the pairing code on your iPhone. Messages run on the Mac with the conversation’s selected provider and model, and replies stream back to the phone.
- Use the same pairing after restarting Vantry. Connect over the local network or configure a compatible HTTPS relay for remote access. Stop sharing from Vantry to disconnect the phone and revoke the code.
- Restore the selected conversation and its connection status when Alma iOS 1.69 opens or reconnects. Retrying a message after a disconnect no longer starts the same request twice.
- Fix a startup race that could mark a run as interrupted while its provider was still starting.
