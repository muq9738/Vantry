# Vantry 0.2.24

- Upgrade the binary delta encoder to full suffix-array `bsdiff` (`qsufsort` with fuzzy forward/backward extension) in the backwards-compatible `vantry-delta-1` format, shrinking single- and cross-version macOS patches by 2x–3.8x and optimizing patch application with buffered I/O and in-memory base reads.
- Publish parallel cross-version skip-list deltas (`N-1, N-2, N-3, N-5, N-8`) via `xtask make-deltas` so updates spanning multiple releases apply in a single compact incremental download instead of falling back to the full archive; raise release metadata capacity to 8 MiB.
- Accelerate in-app downloads with HTTP/2, hedged CN mirror racing (`gh-proxy.org`, `gh-proxy.com`, `ghfast.top`, plus direct fallback), per-chunk stall timeouts, low-speed mirror failover, and seamless HTTP `Range` (`206`) resume, while preferring public mirrors even when a local credential is present.
- Show live connection state and smoothed download throughput (`KB/s` / `MB/s`) in the Software Update dialog and settings progress bar.
