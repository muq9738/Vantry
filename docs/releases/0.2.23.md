# Vantry 0.2.23

- Add unified in-app preview support for images (PNG, JPEG, GIF, WebP, BMP, ICO, TIFF, HEIC, and SVG), code, Markdown, HTML, diffs, and binary files across Markdown links, the Files dock, and message attachments.
- Support workspace-relative paths, home-relative (`~/...`) paths, `file://` URLs with percent-encoding, and line/range anchors (`:42`, `:42:10`, `:10-30`, `#L10-L30`) when clicking links in replies, opening images in a zoomable preview modal and workspace files in the Files reader with line highlighting and scroll-to-line.
- Upgrade the code preview with lightweight syntax highlighting, line numbers, target-line markers, and word-wrap toggling; add rendered/source switching for Markdown, SVG, and sandboxed HTML; and replace dead binary placeholders with a metadata card offering default-app open and Reveal in Finder.
- Parse and render inline Markdown images (`![alt](url)`), allow clicking non-image attachment chips to preview their contents instead of stalling on a loading indicator, and extend Core `files.read` and image validation to support remote images (including WebP) and binary metadata.
