# Vantry 0.1.25

Harden native LAN/relay connectivity, tunnel liveness, zero-secret pairing, certificate rotation, and relay resource bounds.

- **Zero-secret relay pairing & inner-TLS redemption**: Keep long-lived device credentials off the relay during pairing; redeem one-time pairing tokens inside the client-to-host TLS 1.3 channel and verify returned certificates, device IDs, and routes.
- **Pending code quota isolation & cleanup**: Separate pending pairing codes from authorized device records so expired or revoked codes never consume the 128-device quota, clean up remote pending entries on failure/reset/regeneration, and retain retry state when remote revocation fails.
- **Data tunnel liveness & HTTP/2 health probes**: Add independent WSS ping/pong keepalive on data byte tunnels without altering TLS/HTTP read deadlines, and configure HTTP/2 ping timeouts on client transports.
- **Concurrent staggered LAN dial & fresh candidate redial**: Race up to 8 direct candidates with 100ms stagger, fall back to relay after a 1200ms direct grace delay in `auto` mode, refresh mDNS/configured addresses on every redial, and broadcast interface IP updates.
- **Host certificate renewal & relay bounds**: Surface 30-day expiry warnings, pre-issue and distribute next host certificates over authenticated TLS connections, enforce per-route/per-host concurrency limits, trusted proxy extraction, and safe default rejection of insecure non-loopback `http://` relays unless explicitly opted in.

This release pairs with `linkd v0.1.2` across relay and native agent deployments. Pre-existing local workspace MCP work is excluded from `v0.1.25`. macOS Apple Silicon packages use the local signing identity without Apple notarization.
