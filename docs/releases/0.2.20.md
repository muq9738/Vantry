# Vantry 0.2.20

- Automatically accelerate public GitHub release downloads for mainland China users via regional GitHub download proxies with automatic fallback to direct GitHub downloads (configurable via `VANTRY_GITHUB_PROXY`).
- Download multi-step incremental update chains concurrently with buffered disk writes and throttled progress snapshots, and skip incremental deltas when bandwidth savings fall below the threshold (25% for single-step, 35% for multi-step chains) so updates fetch the full package directly instead of rebuilding the app bundle multiple times.
- Split reactive granularity in the Software Update dialog and deduplicate status polling so release notes scrolling and window rendering stay smooth during downloads without regressing to a "Preparing..." state.
