# Vantry 0.1.30

Studio-grade native GPU charts and quota gauges, offline sandboxed WKWebView Artifact Canvas with inline live HTML cards, upgraded 760px Usage analytics, per-hunk Git review and worktree management, interactive `/fork` dialog, and event-driven inter-thread watch wakeup.

- **Studio-grade native GPU charts, math & limits**: Added Studio Hero KPI headers (`hero`, `heroLabel`, `badge`, `badgeTone`, `delta`), inline segmented chart-type switchers, persistent hover/click-to-lock readouts with sibling cross-dimming, a new `breakdown` ranked proportional bar chart with native GPU gradient sparklines, dot-matrix `heatmap` (`style: "dots"` with dashed hollow `null` rings, neutral zero dots, and peak summary footer), `limits` 20-segment discrete pill gauges with 38px circular `%` rings and semantic status pills, native inline/display math rendering (`$$...$$` / `$...$`), CSV/SVG export, and direct MaskAtlas path rendering.
- **Offline sandboxed Artifact Canvas & inline live HTML**: Added `webcanvas` backed by bundled offline Mermaid v11 and KaTeX with strict CSP + WebKit offline content blocker (`vantry-canvas://`), a 2-slot LRU inline live interactive HTML pool with Studio `--v-*` CSS tokens and `ResizeObserver` auto-height, and a right Artifacts dock with `本会话` / `全部` scope switching, color-coded kind tags (`HTML`, `SVG`, `MMD`, `CHART`, `MATH`), version diffing, and click-to-annotate feedback.
- **Upgraded Usage analytics dashboard**: Expanded Usage dialog to 760px featuring a Hero spend/token KPI summary with cache-hit & TTFT pills, 24h activity bar/area chart, `breakdown` by Pi model with chronological sparklines, 7×24 dot-matrix activity rhythm heatmap, and Token mix / cache efficiency donut.
- **Git per-hunk review, `/fork` & event-driven watch wakeup**: Added per-hunk Git stage/unstage/discard and worktree cleanup, an interactive `/fork` dialog supporting model & worktree isolation selection, event-driven inter-thread `thread_watches` auto-wakeup, and updated on-demand `visual-blocks.md` syntax guidance while keeping main parent prompts slim (`< 2400` bytes).

Release packages include both full ZIP archives and `.delta` patches from `0.1.29 -> 0.1.30` (plus bundled repository-scoped read-only `update-token`). macOS Apple Silicon builds use the local signing identity without Apple notarization; Windows x64 remains a cross-compiled preview.
