# Vantry 0.2.13

- Recover stalled event subscriptions with negotiated keepalives and idle detection. Reconnects refresh the selected conversation, and late detail responses no longer overwrite newer execution states. Inserting a message after a run ends starts or queues the next turn instead of repeatedly failing with a conflict.
- Receive completed delegated tasks without waiting for slower siblings. Completion wakes coalesce before execution, survive intervening user turns, and continue delivering later sibling results after a failed wake. Messages sent while waiting for children can run immediately without cancelling those children. Nested delegation, blocking waits, restart reconciliation, and archive checks preserve outstanding work.
- Follow sub-agents in a structured drawer with Markdown replies, folded instructions, reasoning, tool activity, status, and a compact message composer. A sub-agent card sits beside a smaller task list above the main composer, with a stacked layout in narrow windows. Waiting and completion notices make automatic continuation visible.
- Add Rust-based Qoder account and model integration through the plugin panel, with account usage summaries, model discovery, sign-in controls, and plugin update and rollback support.
