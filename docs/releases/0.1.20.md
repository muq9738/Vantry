# Vantry 0.1.20

编排确认卡片、提供方连接与聊天可读性的界面更新。

- 新增原生 `dispatch` 编排确认卡片：一行一个子任务，可勾选启停、选择本机模型、调整并行路数与隔离方式；确认后要求主会话通过单次 `codemode`（`Promise.allSettled`）并发派发，也可选择不拆分直接执行。卡片只保留一层细边框与分隔线，路数和隔离控件悬停才出现。
- Pi 子代理的系统指令按父/子会话区分，移除重复编排手册与图表语法，保留 `codemode` 和 `tool_search`；`ParentTaskID` 由 Core 透传给执行器。
- 提供方设置统一为同一种卡片：Pi、Antigravity、Qoder 与自定义 ACP 都显示安装、登录和连接状态，详细设置按需展开；进入页面自动检测本机 CLI 与账号，支持重新检测。自定义 ACP 改为卡片列表加按需添加。
- Antigravity 支持 agy 自己的 Google 登录（`agy acp --login`），Vantry 打开登录页并接收粘贴的授权码；凭证仍由 agy 保存在系统钥匙串，Vantry 只读取账号名。提供官方安装命令复制；原 Gemini API Key / Vertex 方式保留。测试连接前先保存当前表单。
- Qoder 读取 `qodercli status` 的现有登录，「浏览器登录」在终端打开 `qodercli login` 并自动刷新状态；PAT 入口可直接打开 Qoder 令牌页。
- 回复中的 Markdown 表格自适应阅读宽度，按内容分配列宽并在单元格内换行，不再由横向滚动条遮挡末行；单元格保留加粗、行内代码和链接。
- 用户消息中的图片缩略图可点击放大，支持同轮多图左右切换与 Esc 关闭。
- 轮次导航改为细刻度，预览卡片清理 Markdown 标记并限制两行，不再溢出。

## 安装资产

`vantry-0.1.20-darwin-arm64.zip` 用于 Apple Silicon、macOS 13+，包含主应用、Ghostty 动态库和原生远控 helper。本次采用 **ad-hoc 签名**，未使用 `Vantry Local Signing` 私钥，也未公证；更换签名可能需要重新授予本机系统权限。

`vantry-0.1.20-windows-amd64.zip` 为交叉构建预览，尚未做 Windows 真机验收；安装器自动应用仅支持 macOS。

设置中的更新流程为检查、下载并校验，退出后通过安装命令替换应用并重新打开。运行中不替换应用，有活动任务时拒绝安装。
