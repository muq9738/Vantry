Vantry 0.2.1 refines the native NSH desktop UI, restores full sidebar and composer ergonomics, and resolves macOS clipboard, attachment, and plugin compatibility issues.

- Redesigned the default palette, settings center, empty state, model picker popover, Git branch dropdown, and remote desktop view with a cleaner warm-charcoal / warm-paper visual hierarchy and minimal copy.
- Fixed macOS `Cmd+V` pasting of URLs and plain text into the composer (working around missing `Command::InsertText` on macOS) and added Finder file URI paste support.
- Raised the per-message attachment limit from 8 to 32, added automatic sequential naming for pasted screenshots, and added simplified inline `@图N` / `@name` mentions with matching thumbnail labels and highlighted message bubbles.
- Restored project-row `+` new-thread buttons, removed empty draft placeholder cards, and restored full sidebar thread menu actions (fork into new thread, new thread in project, copy path/branch/link/title/ID, mark unread, filter by project, and open in terminal).
- Fixed plugin manifest deserialization for legacy Go-generated `plugin.json` files containing explicit `null` arrays or maps (such as `vantry-remote-desktop`).

On Apple Silicon, open the disk image and move `Vantry.app` to `/Applications`. macOS 14 or later is required. Existing session and pairing data stay in the application data directory.
