Vantry 0.2.8 makes remote machine sync and interactions fast over relays by eliminating mandatory full-snapshot downloads and pooling peer-proxy connections.

- **On-demand desktop sync instead of full `/v1/snapshot`**: when connecting to a Core that serves `/v1/threads/summaries` and `/v1/threads/detail`, the desktop loads lightweight summaries and the active conversation's bounded detail, then subscribes directly to `/v1/events` without downloading multi-megabyte historical tool outputs from every thread.
- **Persistent `peer-proxy` connection pooling and fast relay routing**: `vantry-service peer-proxy` now reuses idle keep-alive mTLS connections across requests (keeping `/v1/events` on its own stream) and skips the 450 ms direct-LAN wait when relay mode is active, cutting per-request latency from ~800 ms to tens of milliseconds.
