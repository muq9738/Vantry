Vantry 0.2.7 fixes slow remote sync loops over bandwidth-constrained relays and automatically replaces idle outdated local Core processes after an upgrade.

- **Compressed Core HTTP responses**: `vantry-core` and `vantry-client` now negotiate `gzip` compression for JSON payloads (including `/v1/snapshot`, `/v1/threads/summaries`, and `/v1/threads/detail`), dramatically reducing snapshot transfer size over relays.
- **Interactive UI without waiting for full snapshots**: the desktop workbench clears its loading notice as soon as thread summaries and bounded conversation detail arrive, and keeps the active conversation visible if a background snapshot retries.
- **Stable relay streaming and snapshot backoff**: `vantry-connectivity` prioritizes WebSocket control frames (`Pong` and heartbeat `Ping`) over bulk binary transfer to prevent ~80s heartbeat-expiry disconnects during large downloads, and snapshot retries now back off up to 30 seconds.
- **Automatic outdated Core replacement**: `/v1/status` now reports the Core package version; `vantry-service ensure-core` and desktop startup automatically drain and replace an idle outdated local Core while leaving busy Cores undisturbed.
