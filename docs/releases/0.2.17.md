# Vantry 0.2.17

- Fix in-app macOS updates deadlocking with `quit the application before installing` when a Qoder `model-plugin-host` sidecar is running under the bundle. The updater now recognizes `model-plugin-host` as a Core-managed process—draining an idle Core (and cleaning up orphaned plugin hosts left by older Cores) or keeping it alive alongside a busy Core when `--allow-busy-core` is set.
- Gracefully shut down the detached Qoder `model-plugin-host` when Core exits so idle Core shutdowns and restarts leave no orphaned plugin host processes.
