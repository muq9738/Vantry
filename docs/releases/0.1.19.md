# Vantry 0.1.19

修复会话误用离线演示、消息与附件编辑、文件阅读和任务结果回传，并完善私有仓库更新检查。

- 新会话不再恢复旧的离线演示偏好；误建的演示会话可选择模型并切换至 Pi。模型旁显示独立的思考强度入口。
- 用户消息支持整条复制、拖选及同轮跨消息复制。图片保留缩略图，同时在粘贴位置插入对应文件名引用；重开窗口后可恢复缩略图。
- 运行中默认追加信息，Cmd／Ctrl 点击切换为排队；默认方式持久保存。队列显示在输入区上方，支持立即发送、主输入框编辑、移除和调序，编辑完成后恢复原草稿。“立即发送”改用原子队列操作。
- 本地文件链接打开右侧阅读器；Markdown 默认渲染预览，可切换自动换行的源码视图，目录可收起。支持行号定位和长文滚动。
- Pi 原生子代理与应用委派分开处理，移除原生能力硬拦截，默认沿用用户的 Pi 扩展和 MCP。禁止默认模型不同的远端任务静默切换模型。
- 慢快照不再阻塞远端事件消费；指定 taskId 可以跨用户轮次查询任务结果。
- 更新检查每次重新读取专用 token，新增或轮换后无需重启；设置页显示具体配置错误，下载不再沿用普通工具的短超时。

## 安装资产

`vantry-0.1.19-darwin-arm64.zip` 用于 Apple Silicon、macOS 13+，包含主应用、Ghostty 动态库和原生远控 helper。本次采用 **ad-hoc 签名**，未使用 `Vantry Local Signing` 私钥，也未公证；更换签名可能需要重新授予本机系统权限。

`vantry-0.1.19-windows-amd64.zip` 为交叉构建预览，尚未做 Windows 真机验收；安装器自动应用仅支持 macOS。

设置中的更新流程为检查、下载并校验，退出后通过安装命令替换应用并重新打开。运行中不替换应用，有活动任务时拒绝安装。

## 验证

本机全仓 Go 测试、vet 与差异格式检查；调度、队列和消息交互的相关 race 检查。原生 UI 测试覆盖拖选复制、附件位置、追加／队列、编辑草稿保留、文件预览与源码换行。没有将临时 Core 或合成截图当作 Windows 真机验收。
