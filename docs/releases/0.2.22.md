# Vantry 0.2.22

- Paired computers try the local network first and use the host's configured Alma relays when a direct connection is unavailable. When a computer returns to the LAN, new requests can switch back to a direct connection while existing transfers finish. Computers on the same LAN can also pair while the relays are offline.
- Alma iOS can reconnect to the same shared conversation over Wi-Fi or the public relay using its existing pairing. A public invitation starts at the relay. After the encrypted handshake, Vantry supplies the Mac's current LAN addresses and port.
- Desktop hosts can register with a primary and backup Alma relay. The legacy T3 mobile gateway has been retired. Devices paired through Alma keep their existing authorization.
- Gemini Web receives the current message exactly as entered, including whitespace and line breaks. Other Gemini models continue to use the configured Pi instructions, conversation history, and tools.
