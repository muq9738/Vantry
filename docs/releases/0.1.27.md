# Vantry 0.1.27

Slim down Pi worker system prompts with turn-stable KV caching, keep routine parallel file inspection on native tools instead of `codemode`, and protect multi-section `codemode` results from merged truncation.

- **Turn-stable slim `workerInstructions`**: Offload full multi-agent orchestration rules (`orchestration.md`), 11 MyGo GPU visual block grammars (`visual-blocks.md`), and `vantry ctl` commands (`cli-fallback.md`) to on-demand files under thread-stable `<dataDir>/instructions/...`, reducing main-thread `<addendum>` from `9,911` B to `2,168` B (`2,395` B with MCP) and keeping `instructions.md` byte-identical across resumed session turns.
- **Child session tool deferral**: Inject `VANTRY_PARENT_TASK_ID` into delegated child Pi workers so parent-only orchestration tools (`vantry_orchestrator_capabilities`, `vantry_delegate_task`, `vantry_task_status`) are deferred on children instead of flooding child tool declarations and `<rules>`.
- **Un-hijack native parallel retrieval**: Override `builtin:codemode`'s blanket `"instead of many separate calls"` `<rules>` guideline and snippet via `before_agent_start`, and strip `Codemode:` suffixes from `read` / `grep` / `find` / `ls` descriptions via `prepareLoadout` while keeping them callable inside scripts when needed.
- **Anti-merged-truncation `codemode` rebalancer**: Intercept spilled `codemode` results in `tool_result` (`details.fullOutputPath`) and apply water-filling per-section budget allocation across `==> text k/N <==`, `<console_output>`, `Script error:`, and multi-entry JSON arrays/objects so small middle items stay intact and oversized sections carry `[Full section: <path> lines X-Y]` pointers instead of silent middle truncation.
- **Plan-mode read-only deep investigation**: Inject full-chain investigation guidance (`configuration & data sources -> form / UI / handler state & validation -> submission, side effects & persistence`) whenever `interaction_mode == "plan"`.

This is the first GitHub Release since `v0.1.24`, cumulatively shipping `0.1.25` (LAN/relay connectivity, pairing, keepalives, and limits hardening) and `0.1.26` (Pi-only runtime and codemode-first native MCP) alongside `0.1.27`, using existing `linkd v0.1.2` infrastructure. Release packages include the repository-scoped read-only `update-token` for out-of-the-box in-app updates. macOS Apple Silicon packages use the local signing identity without Apple notarization; the Windows x64 ZIP remains a cross-compiled preview without native remote-desktop hardware validation.
