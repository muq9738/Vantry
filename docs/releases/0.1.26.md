# Vantry 0.1.26

Focus Vantry exclusively on the native Pi runtime (`pi --mode rpc`), drop legacy ACP adapters (`agy`, `qoder`, custom ACP), and ship Codemode-first native MCP management.

- **Pi-only execution runtime**: Remove `internal/adapters/provider/acp` and desktop ACP configuration/picker code; keep durable detached `pi --mode rpc` execution, streaming `agent_settled`, live steering, and safe migration for historical ACP threads onto Pi when switching models.
- **Codemode-first native MCP**: Enable `builtin:mcp`, `builtin:codemode`, and `builtin:tool-search` consistently in Pi workers (including when `--no-extensions` is active), guide workers to discover and batch `tools.mcp__*` calls inside the QuickJS sandbox, and default newly saved full servers in `.pi/mcp.json` / `~/.pi/agent/mcp.json` to `"exposure": "codemode"`.
- **Dual-scope MCP, project trust & live probe**: Add user/project MCP editing, inline exposure switching (`codemode` / `deferred` / `direct` / `hidden`), `mcp.remove`, explicit `~/.pi/agent/trust.json` control (`mcp.trust`), and on-demand `pi mcp list --json` live probing (`mcp.probe`) with redacted endpoints.
- **Startup diagnostics & schema guard**: Allow 30s Pi RPC startup handshakes (`rpcStartupTimeout`) for slow user extensions, reject newer SQLite schema versions before mutating persistent journal settings, and surface Core startup failure logs in a native macOS dialog.

This release uses the deployed `linkd v0.1.2` infrastructure without changes. macOS Apple Silicon packages use the local signing identity without Apple notarization.
