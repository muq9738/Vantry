# Vantry 0.1.32

Bundles the standalone Pi runtime inside Vantry packages for zero-dependency out-of-the-box execution, adds one-click Pi upgrades with automatic China/direct mirror routing, and introduces a native first-run model configuration wizard writing directly to `~/.pi/agent` without symlinks.

- **Bundled standalone Pi & seamless local fallback**: Release builds now bundle the standalone `earendil-works/pi` binary (`v1.6.0`, no local Node.js/npm required). In `auto` mode, Vantry follows an existing local `pi` installation when present and falls back cleanly to the bundled or Vantry-managed standalone binary; users can switch runtime source anytime in **Settings → Providers**.
- **One-click Pi upgrade with automatic CN/direct mirror selection**: Check for updates and upgrade Pi in-place from **Settings → Providers**. Automatically probes `registry.npmjs.org` vs. Taobao `registry.npmmirror.com` and `github.com` vs. verified GitHub release proxies (`edgeone.gh-proxy.org`, `gh-proxy.org`, `ghfast.top`), verifies official `SHA256SUMS` digests and binary startup before activation, and supports manual mirror overrides.
- **First-run Pi model setup wizard (no symlinks)**: When no models are configured yet, Vantry shows an onboarding prompt on the home screen and empty model picker to configure DeepSeek, OpenAI, Anthropic, Gemini, OpenRouter, Kimi, custom OpenAI/Anthropic-compatible endpoints, or terminal OAuth sign-in, non-destructively merging into standard `~/.pi/agent` (`auth.json`, `models.json`, `settings.json`).

Release packages include both full ZIP archives (with bundled standalone Pi) and `.delta` patches from `0.1.31 -> 0.1.32` (plus bundled repository-scoped read-only `update-token`). macOS Apple Silicon builds use the local signing identity without Apple notarization; Windows x64 remains a cross-compiled preview.
