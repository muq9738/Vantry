# Vantry 0.2.14

- Run interactive terminals on the machine that owns the conversation or workspace. Paired Unix hosts expose authenticated PTY sessions with input, resize, interrupt, bounded output, and cleanup. Agent terminal requests follow their originating conversation, including delegated worktrees. Shell code blocks offer a Run in Terminal action.
- Copy conversation titles as links with both Markdown and HTML clipboard formats. Links use the owning Core's environment identity and resolve across paired hosts. Pasted HTML links become conversation references. The header's More menu now uses a native popup.
- Replace the sub-agent and task-list cards above the composer with a compact status bar and an expandable overlay. Simplify delegated instructions and reasoning in the drawer, remove the input scroll indicator, and use a clearer send button.
- Drop files anywhere in the conversation to attach them. Remote conversations upload file contents instead of falling back to local paths. Running conversations use a compact send-mode menu, and queued messages have inline actions.
- Add a shared Git branch picker with search, recent branches, local and remote folder groups, tags, upstream status, and branch actions. Local and remote workspaces share validated Git operations, including checkout, worktree creation, compare, merge, rebase, update, push, rename, and protected deletion.
- Fix project-directory selection losing its session context when the picker closes. Preserve unsent text when opening a draft in another directory or switching machines, and finish session selection before closing a sub-agent drawer.
- Allow follow-up messages to sub-agents loaded beside their parent in summaries mode. Explain when synchronization prevents sending instead of silently ignoring the action.
- Continue an attempt after an empty, unexplained upstream model error, with at most two retries. Explicit provider errors and user cancellation retain their existing handling.

## Compatibility

Paired hosts need the updated Core for remote PTY sessions. Remote PTYs currently require Unix hosts; Windows hosts return an explicit unsupported-platform message. Git updates use fast-forward merges. New worktrees are created beside the repository.
