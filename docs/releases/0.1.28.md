# Vantry 0.1.28

Upgrade Vantry's in-app updater with one-click restart-and-update, true binary incremental (`.delta`) patches, and clean Settings update layout.

- **One-click "重启并更新" (Restart & Update)**: After downloading and verifying an update, the Settings primary button switches from **下载更新 / 下载增量更新** to **重启并更新** (`update.apply`). Clicking it confirms Core has no active runs, launches the newly staged bundle's detached `apply-update --wait-pid <pid>` helper, cleanly quits the desktop window, drains idle Core safely without ever killing active tasks, swaps `/Applications/Vantry.app`, cleans temporary staging files, and relaunches Vantry automatically.
- **Pure-Go binary incremental updates (`.delta`)**: Added `bsdiff`/qsufsort binary diffing and `os.Root`-confined reconstruction (`WriteDelta` / `ApplyDelta`) verified by exact byte count, SHA-256 per file, and macOS `codesign --verify --deep --strict`. Unchanged files (including bundled read-only `update-token` and assets) copy locally with 0 payload bytes, while any corrupted or mismatched delta automatically cleans up and falls back to downloading the full ZIP archive.
- **Clean Settings update UI**: Show delta availability and patch size beside full package size, fix status/error wrapping and horizontal clipping (`FillWidth().Wrap()`), keep `安装更新.command` accessible via a secondary **复制安装命令** button (and as the automatic fallback for remote sessions or non-writable install directories).

Release packages include both full ZIP archives and `.delta` patches from `0.1.27 -> 0.1.28` (plus bundled repository-scoped read-only `update-token`). Installing `0.1.28` from `0.1.26`/`0.1.27` uses the prior updater once; updates starting from `0.1.28` onward use binary `.delta` and one-click restart natively. macOS Apple Silicon builds use the local signing identity without Apple notarization; Windows x64 remains a cross-compiled preview.
