Vantry 0.2.0 brings the native NSH desktop, persistent Core, embedded Pi worker and standalone relay into one Rust workspace.

- Open a paired Rust Core from a v0.1.42 desktop using its existing identity and session relay. The Core restores configured relays at startup and reports the capabilities the older machine menu checks before opening a session.
- Browse files and Git history on a paired Core, review diffs, manage worktrees and run delegated tasks on the machine that owns the checkout.
- Preview image attachments from the owning Core. Use the integrated terminal for interactive tools and approvals.
- The built-in SSH environment launcher has been retired. Paired Core connections and Git SSH remotes remain available.

On Apple Silicon, open the disk image and move Vantry.app to Applications. macOS 14 or later is required. Finish active tasks before restarting the Core. Existing session and pairing data stay in the application data directory.
