Vantry 0.2.4 reduces the installed size of the macOS app and improves session startup while keeping the embedded Pi Rust runtime.

- The desktop shows thread summaries and the selected thread’s latest 20 runs while full history loads. New drafts and conversations with confirmed activity state can send during that load. Conversation rendering groups tool activity by run.
- When Core starts with Pi and user MCP enabled, it preloads the tool list for eligible global loopback HTTP servers in the background. Ordinary turns reuse Pi’s catalog. Workers connect when they call a tool, and explicit lifecycle settings, direct tools, credentials and project trust keep their existing behavior.
- Pi now prepares the native retrieval-tool descriptions in Rust. The model-only secret prompt keeps its native UI and private file handoff.
- Core commits consecutive streaming deltas together while keeping the first output and interactive events responsive.
- Core and Desktop use separate size-optimized release profiles. The macOS release includes the remote-desktop helper and checks the complete signed app against a 50,000,000-byte limit.
- The command-line client accepts paired-device IDs that begin with a hyphen when connecting or revoking access.
