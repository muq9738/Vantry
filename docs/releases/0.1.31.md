# Vantry 0.1.31

Streamlines per-conversation UX and Core execution by removing the Project Coordinator chat mode and cross-thread milestone card broadcasts while preserving existing local databases and protocol compatibility.

- **Cleaner conversation UI & sidebar menus**: Removed the Project Coordinator header, `project_updates` milestone cards from timelines and subagent transcripts, the context strip "Open project chat" button, and the sidebar thread context-menu project-chat entry.
- **Simplified Core & Pi orchestration**: Removed `project.chat.open` dispatch, `project_updates` snapshot/timeline/projection queries, automatic `projectCoordinatorPrompt` input wrapping, and `ProjectCoordinator` direct orchestration overrides so every session follows the slimmed on-demand worker instructions uniformly.
- **Backward compatibility preserved**: Retained SQLite schema definitions (`threads.project_path`, `project_updates`), `DELETE FROM project_updates` cleanup on rewind, legacy `project.updated` event ignoring on Desktop, and wire types in `pkg/api` so existing `state.sqlite` databases open without migration friction.

Release packages include both full ZIP archives and `.delta` patches from `0.1.30 -> 0.1.31` (plus bundled repository-scoped read-only `update-token`). macOS Apple Silicon builds use the local signing identity without Apple notarization; Windows x64 remains a cross-compiled preview.
