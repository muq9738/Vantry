# Vantry 0.1.29

Pure Pi default execution, anti-hang/anti-loop guardrails, live telemetry & usage tracking, visual Git checkpoints & Rewind, lightweight cross-thread Inbox, granular session approvals, and optional macOS Seatbelt workspace isolation.

- **Pure Pi default & anti-hang/anti-loop guardrails**: Slimmed Pi default prompts and deferred multi-agent orchestration tools unless running as a project coordinator; added `ToolLoopGuard` repeat-error circuit breaker, oversized tool output pruning with head/tail truncation and encoding/anti-bot diagnostic hints, Pi RPC silence watchdog, and live tool target + silence warning/Stop UX.
- **Live telemetry, usage ledger & smoother streaming**: Wired real token/context/cost/TTFT/tok/s telemetry with `<dataDir>/usage-ledger.json` persistence, periodic Core event pruning (`PruneEvents`), 16ms streaming frame coalescing, compact composer telemetry strip, real Usage dialog metrics, and compaction/retry banners.
- **Git checkpoints, visual Rewind, Pi/Claude keyboard flow & zero-clutter Inbox**: Auto pre-run workspace snapshots (`git.checkpoints.*`), `thread.rewind` with Pi session truncation and visual Rewind dialog (conversation-only or conversation + workspace restore), `Ctrl+O` / `Ctrl+T` global toggles, safe two-tap `Esc` stop/rewind flow, and lightweight cross-thread Inbox badge.
- **Granular approvals & optional macOS Seatbelt sandbox**: Read-only bash allowlist under `auto-accept-edits`, per-thread session grants (`允许本次` / `本会话允许 <scope>` / `拒绝`), and optional macOS `/usr/bin/sandbox-exec` workspace write isolation protecting `.git/hooks` and `.git/config` (Settings → Agent & Permissions).

Release packages include both full ZIP archives and `.delta` patches from `0.1.28 -> 0.1.29` (plus bundled repository-scoped read-only `update-token`). macOS Apple Silicon builds use the local signing identity without Apple notarization; Windows x64 remains a cross-compiled preview.
