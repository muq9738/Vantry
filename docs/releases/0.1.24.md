# Vantry 0.1.24

Reduce T3 snapshot payloads for clients that explicitly support compact turn items.

- Honor boolean `acceptCompactTurnItems: true` on thread subscriptions. Omit the duplicate local-visible prefix from the wire `turnItems` array and mark snapshots with `turnItemsOmitLocalVisible: true`.
- Preserve `visibleTurnItems` and the complete internal projection so subsequent incremental updates retain their existing behavior.
- Keep full snapshots for clients that do not opt in and whenever the local-visible prefix cannot be restored safely.
- Apply the negotiated format to initial snapshots, structural fallback snapshots, and reconnect snapshots. Run-state and structural fallback rules remain unchanged.

The 41-run fixture decreases from 443,299 B to 303,454 B, a 31.5% reduction before WebSocket compression. This is a fixture measurement, not a fixed savings rate for every conversation.

Lossless restoration was verified with T3's upstream `restoreLocalVisibleTurnItems` implementation for ordinary history and a mixed projection containing large tool output, reasoning, approvals, queued input, and steering. Tests cover strict capability negotiation, prefix ordering and content, legacy behavior, subsequent deltas, fallback, and reconnect.

This patch does not require a linkd update. macOS Apple Silicon packages use the existing local signing identity and are not Apple-notarized. The Windows x64 ZIP remains a cross-compiled preview without native remote-desktop hardware validation.
