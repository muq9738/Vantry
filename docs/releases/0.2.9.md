# Vantry 0.2.9

- Conversations in the same project directory can start concurrently. A conversation waiting for approval no longer blocks another conversation from reaching the model.
- Send a follow-up to the current turn or queue it for the next turn. Queued messages now appear above the composer with an action to insert them into the running turn. The conversation shows delivery confirmation or an error.
- Copying a text selection containing an image reference includes the image. Pasting into another draft on the same machine remaps image numbers and preserves repeated references.
- Draft titles summarize topics locally. Short, standalone requests can keep their title without an extra model call.
- Desktop updates from 0.2.8 can use verified delta downloads on macOS arm64 and Windows x64. Update settings show the download size and savings when a smaller patch is available.
