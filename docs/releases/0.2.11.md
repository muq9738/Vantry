# Vantry 0.2.11

- Inspect category values by hovering over a chart. Bar charts show negative values around zero, combo charts support a separate right axis, and date labels adapt to the range. Large pie charts group small slices into a labeled total. HTML and SVG replies have a themed inline preview with zoom and an expanded view.
- Follow an agent’s task list above the composer. The list shows the current step, completed items and overall progress. Updates belong to the conversation that produced them, including delegated conversations.
- Connect another desktop from Settings → Environments using a one-time pairing link. Hosts can require approval of new desktop devices. Compare the code shown on both computers before approving. A revoked desktop credential prompts the active client to pair again. Existing desktop pairings continue to work.
- Update a plugin from its card when an update is available. The Git panel shows the tracked upstream and ahead/behind counts, and the conversation overview distinguishes child task outcomes by status.
