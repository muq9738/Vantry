# Vantry 0.2.15

- Decouple conversation timeline projection around a unified monotonic per-run sequence axis (`run_blocks`, SQLite schema v12). Core persists initial prompts, multi-segment reasoning, text blocks, tool calls, mid-run steering messages, approvals, and terminal status blocks in causal order, with automatic migration backfill for existing databases and a legacy fallback for older Cores.
- Render mid-run steering messages as first-class timeline rows at the exact point where they were delivered—below existing thinking and tool calls and above subsequent output—instead of grouping them under the initial user prompt.
- Support multiple independent reasoning and text blocks within a single run, with accurate per-block streaming indicators and O(1) incremental Markdown updates.
- Add a vertical turn-navigation dot rail along the left edge of the timeline for jumping directly to any turn with previews and active-turn tracking.
- Scope the pinned task list above the composer to the thread's latest run and settle lingering in-progress items once a run finishes, while guiding agents to record a final completed task-list update before replying.
- Stabilize sidebar project and thread row layouts on hover by overlaying action controls instead of reflowing row widths.

## Compatibility

Local SQLite databases upgrade automatically from schema v11 to v12 and backfill `run_blocks` for historical runs. The desktop app continues to render conversations from older paired Cores using its legacy fallback.
