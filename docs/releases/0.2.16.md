# Vantry 0.2.16

- Support multi-version chained binary delta updates: when upgrading across multiple releases (for example `0.2.13 → 0.2.16`), the updater discovers intermediate releases, plans the minimum-byte incremental patch chain via shortest-path search, applies patches sequentially with per-step cleanup and signature verification, and falls back to the full archive if any step fails.
- Aggregate release notes across all skipped versions between the installed release and the latest release.
- Add real-time download, delta-patching, and verification progress reporting (`phase`, `downloadedBytes`, `totalBytes`, `deltaSteps`, `deltaStep`, `error`) with non-blocking `update.status` polling while downloads run.
- Introduce a dedicated Software Update modal dialog featuring version transition details, incremental size/savings badges, scrollable release notes, a live progress bar, a completion banner ready to install, and **Skip This Version** / **Later** / **Update Now** / **Restart Now** actions.
- Add quiet startup update checks with persisted skipped-version preferences, a compact sidebar update banner when an update is deferred, and live progress in Settings → About & Updates.

## Compatibility

Older desktop clients and Cores remain wire-compatible: all new `AppUpdateInfo` progress fields are optional and omitted when empty or zero.
