# Vantry 0.1.21

Private release packages can include a dedicated read-only update credential restricted to this repository, allowing recipients to check for and download updates without configuring each computer separately.

- Prefer the local dedicated credential; use the bundled `update-token` only when the local file is absent.
- Require private permissions for local overrides and reread credentials on each update check.
- Keep the packaging input `resources/update-token` out of Git. Bundled credentials must grant only repository Contents and Metadata read access.
- Show actionable update errors from Core, including repository access, credential permissions, and download failures.
- Preserve staged installation: the updater replaces the application only after its windows and workers have exited and Core is idle.

This version was installed locally before publication. Its changes are included in the subsequent 0.1.22 release.
