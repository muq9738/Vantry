# Vantry 原生工作台架构

本页描述组件归属和业务合同。当前通过项见[功能清单](current-functions.md)；尚未完成的行为见[能力边界](behavior-gaps.md)。研究快照不随仓库分发，依赖与适配材料的来源见[第三方 notices](../THIRD_PARTY_NOTICES.md)。

## 依赖方向

MyGo 原生 UI → 私有 IPC 客户端 → Core API → 命令策略与编排内核 → SQLite 事务。Provider、工作区、插件和网络是内核依赖的端口实现，内核不依赖界面或具体中继。

Core 保存事件、查询投影、命令回执、Outbox、任务关系与交付状态。Provider worker 执行外部工作，再把规范化事件提交给 Core；插件不能直接修改业务数据库。

## 进程与所有权

- Desktop 持有原生窗口、输入焦点、本机观看器及环境视图；关闭窗口不会取消已提交任务。
- Core 持有数据库、环境身份、工作区、Provider 和被控服务。先取得实例锁，完成迁移与恢复，再进入ready。
- Worker 按Attempt持有Pi和流式事件游标，执行权与Core投影分别持久化。
- 子任务有独立线程、Run、Attempt、workspace与generation；父轮完成不代表整个子任务完成。
- 每个远程环境提供自己的模型、目录、草稿和事件流，未知目标不能回落本机。

停止窗口、停止运行和停止Core是三种操作。升级旧Core仅在确认空闲后轮换，活动任务保持运行，不用构建号或内容摘要当作兼容门槛。

## 命令与事务

1. API校验输入、身份、协议和实际能力。
2. 以commandId查询回执，同内容重试返回原回执，异内容复用拒绝。
3. 在按线程串行的决策区读取状态并生成事件及效果。
4. 单个事务提交事件、投影、回执与Outbox。
5. 提交后发布有序序列并唤醒执行器。
6. 执行器的输出再次按Run/Attempt/归属校验写入，过期回调不得改动新执行。

数据库唯一约束是最终去重保障。线程并行不等于SQLite多写者；外部进程、网络和模型调用不在数据库写事务中等待。命令幂等、Provider事件去重和外部副作用幂等分别处理。

## 取消与恢复

Outbox执行权、停止意图、结果交付和父续行均需持久状态。取消先保存意图，再关闭相应执行资源；不能因一次超时就重新提交原prompt。状态不明应保留未知语义，并按权威回执查询。

重启恢复核对执行身份、工作区归属、worker状态和事件游标；未确认旧执行结束前不启动新的目录写入者。子任务交付按generation推进，已交付结果不重复触发父续行。

Windows进程归属使用自有Job，文件与目录使用SID/DACL、重解析点校验和LockFileEx；Unix保留进程组、继承锁描述符及flock。两种实现都必须避免杀错进程或将旧任务与后续合法写入者混淆。

## 工作区

Core准备或验证工作区，持久保存owner、仓库、分支和准备状态。准备失败不会回落主目录；活动写入持有稳定目录锁。清理、Git写操作和项目初始化都需核对归属，不仅看路径文本。

未暂存内容、hooks、签名失败和分支漂移按实际结果保留。checkpoint辅助代码不等同完整对话与工作区回退合同。

## 查询与订阅

快照和增量通过high-water序列衔接；UI以已提交投影为准。订阅取消、背压与游标失效须显式呈现，不能拼接不完整历史。远端事件游标与本机proxy事件身份分开，避免重复文本、工具或审批。

## 插件和界面

脚本插件通过moejs执行，Native和Process执行器有各自生命周期；共同使用明确DTO和事件流。资源、context、取消、超时、内存及输出边界按实际宿主能力定义，不承诺完整Node/npm环境。

原生面板保持稳定key、焦点、阅读位置和异步结果归属。IME只提交已确认文本；远程焦点下的输入不被本机全局快捷键抢走。未授权插件、未实现API与缺少系统组件必须显示原因，不能用空结果伪装成功。

## 远程连接与桌面

设备配对保存独立身份与凭据，端点通过TLS保护Core API，中继只路由不透明连接。SSH复用已有认证，不改全局配置。协议实现和使用者分别承担各自身份、权限及资源归属。

远程桌面引擎在独立插件仓库维护。HostStart/Stop/Status/权限操作归目标Core，viewer归本机窗口；本机不能使用远端返回的SSH配置路径。安装和启动不请求系统权限，只有用户主动开启时进入授权流程，取消或离页不后台开共享。

## 验收

按风险选择业务回归、进程/恢复测试、原生窗口和真实双机验证。构建与交编不是运行通过，模型目录不是实际模型执行，测试进程的系统权限不能替代正式App。Windows真实GPU、屏幕、输入及平台内核行为必须独立验证，不能沿用Mac结论。
