# 原生桌面界面与交互

Vantry 使用 Go + MyGo 原生组件与 **Stardust（星尘）** 视觉语言，提供浅色暖纸侧栏（`#F6F5F3`）配纯白阅读画布（`#FFFFFF`）、深色石墨侧栏（`#1C1D21`）配深灰画布（`#16171A`）、火橙主强调色（浅色 `#FF5A1F` / 深色 `#FF6A2B`）、透明原生标题栏、浮起输入卡与连续阅读列。正式程序不使用 HTML 或 WebView 界面。

源码版本以 `mygo.json` 为准。本文描述当前桌面端的布局、输入、复制与文件阅读交互。

## 打开与构建

```sh
open dist/darwin-arm64/Vantry.app
GOTOOLCHAIN=go1.27.3 go tool mygo build -platform darwin/arm64 -skip-dmg
```

默认窗口为 1280×820，最小 640×420；更窄布局也有组件回归。保留 macOS 窗口按钮，标题区可拖动。开发构建、私有数据目录和 Pi 配置见 [本地启动与开发](getting-started.md)。

## 布局与 Stardust 界面模块

- **首页**：把欢迎语与 760 px 居中输入卡放在同一焦点区域；已选项目时在右上角提供浮动项目快捷卡。
- **左侧栏（Stardust 分区导航）**：
  - 默认列出全部已配对机器和本机的会话。「全部机器」菜单只筛选列表。在同一窗口点会话或项目，操作随该项发往所属 Core。其他机器连接失败时仍能继续当前会话。
  - 顶部为带 `⌘K` 提示的圆角搜索栏、项目筛选、添加项目与新建按钮。
  - 按状态自然分区：**运行中 · N**（含实时迷你进度条与状态文字）、**待我处理 · N**（橙色计数角标，汇聚待授权、未确认、有新结果与异常会话）、**已置顶**，以及按项目分组的 **分类**（确定性 10 色项目首字母徽标、可折叠、项目内新建入口、超长时“更多 N”展开）。
  - 选中行以带投影的 10 px 圆角浮起卡片呈现，保留键盘导航、首字母定位、拖拽置顶/归档与悬停预览卡；底部提供设置、Git、用量、快捷键与明暗切换；不常驻显示版本号，启动后及每 6 小时静默检查更新，仅在有新版本时出现带橙点的小更新图标，点开进入 设置 › 关于。
  - 持久线程标题作为权威，重命名不会被首条指令覆盖；无内容历史空线程不占列表但没有从 Core 删除。
- **顶栏**：左侧展示 `项目 / 会话标题` 面包屑与状态胶囊；宽屏右侧在存在真实上下文/令牌数据时显示可点击的用量胶囊（无数据时自动隐藏），其后为分段工具切换胶囊与右侧面板开关。
- **连续阅读列与时间线**：
  - 对话使用最多 760 px 的连续阅读列，用户消息靠右，正文与底部输入区对齐。
  - 连续工具调用汇总为可读的步骤卡片（如“运行 2 条命令，读取 1 个文件”），展开后呈现圆角描边容器、缩进时间线轨与原始命令/输出代码井。
  - 表格列宽参考单元格内容，长说明按列换行。图表按阅读列宽度绘制，支持查看源码和放大。
  - 审批卡采用暖琥珀底色与描边，展示实际命令与清晰的“拒绝 / 仅允许本次”操作按钮。
- **推理强度滑块**：点选即刻生效（乐观更新），模型切换仍在提交时新的选择排队、完成后再发送；滑块旋钮与尾焰在独立图层上用姿态动画平移，只重绘不重建视图，系统“减少动态效果”时直接到位。
- **输入卡与状态底栏**：
  - 输入区为 16 px 圆角浮起卡片，占位提示“问点什么… @ 文件、$ 技能、/ 命令”。
  - 卡片左下角提供 `+` 附件/子任务菜单、上下文占用环形胶囊（有真实遥测数据时显示）与规划模式开关；右下角依次为带浅色底纹的权限胶囊（自动 / 改文件自动 / 询问）、统一的模型与思考强度胶囊（提供方图标 + 模型名 + 彩色强度点）以及橙色圆形发送/停止按钮。
  - 卡片下方保留运行环境、项目与分支上下文条，并在会话中呈现安静的实时状态底栏（`● 第 N 轮 · 状态 · M 步 · 耗时 · 令牌 / 缓存`），仅展示真实已有字段，不虚构未知指标。
- **右侧面板**
  - 点右上角的面板按钮打开会话概览。变更行进入 Git 详情，来源行进入 MCP 服务列表。
  - **工具坞** 依次为会话概览、文件、Git、终端、插件、MCP。**终端** 合并本机与远程：首个“远程主机”标签列出 SSH 主机（连接、添加、检测），本机终端在项目目录（无会话时为所选目录或主目录）打开；运行在其他机器上的会话不会开本机 shell，而是匹配同名 SSH 主机或引导到主机列表。
  - 点 **子智能体** 下的状态计数展开任务，点任务查看详情。返回后仍在父会话。左侧栏只列主会话，搜索子任务名称可以从父会话行打开命中项。

## 输入与执行

新会话先是本地草稿，首次发送才创建持久线程。首次快照加载前，绘制界面不会创建会话；加载到空工作区后才初始化一个本地草稿，避免抢走正在恢复的真实会话。

输入区在含图片或会话引用的草稿中使用 NSH 富文本编辑器。点蓝色下划线的 `@图1` 可在发送前预览附件，发送后仍可点消息中的引用打开同一附件。普通草稿使用原生多行输入框。新安装默认 Enter 发送、Shift+Enter 换行；也可设置 Ctrl+Enter 发送、Enter 换行。Cmd+Enter 始终换行。保留用户已保存的偏好，组合输入期间不抢走确认键。发送后焦点回到输入框。

运行中默认“追加信息”，交给当前任务；不能追加的运行使用队列。发送方式菜单可切换为“加入队列”，选择会跨重启保留；Cmd／Ctrl 点击发送按钮执行另一种方式。排队消息直接显示在输入框上方，可立即发送、编辑、移除或调整顺序。编辑使用主输入框，保存或取消后恢复之前未发送的草稿；附件替换须由 Core 验证并与正文一起保存。“立即发送”使用一次原子队列操作，不先取消再另发。

排队持久保存到 Core；Steer 精确指向当前 Pi Attempt。停止按钮取消该线程未开始的队列。已开始的队列消息进入正常对话；已送达的 Steer 留在对应轮次，失败、等待与交付不明分别显示；交付不明不会自动重发，Pi 接收也不代表模型已消费。

发送或控制回执未确认时，重试沿用原 commandId 和原始内容，保留后来编辑的草稿。即使原 Run 已结束，未确认的排队控制仍有重试入口。

## 文字、附件与文件阅读

用户消息和回复支持鼠标拖选、Cmd／Ctrl+C；同一轮的消息和回复共享选择范围。用户消息旁提供整条复制按钮。复制文本保留附件引用在正文中的位置。

图片同时保留输入区上方的圆角缩略图与光标处的短文件名引用；PDF、文件以小标签呈现。附件真实内容由 Core 保存，正文引用与附件 ID 关联，删除卡片时移除对应引用。重开窗口后从所属 Core 读取缩略图，避免恢复草稿后只剩文件名。

点击本地文件链接在右侧打开。阅读时目录默认收起，可用目录按钮展开；Markdown 默认渲染预览，可切换源码。源码自动换行，长段落和代码行不因工具坞变窄而横向截断，内容可纵向滚动。带行号的文件链接打开源码并定位。

## 模型、项目和权限

模型目录在后台从本机 Pi 读取。输入区中的模型选择器支持搜索、原生列表和手输 ID。通过 `thread.model` 更新当前会话的后续消息；已开始的 Run、Attempt 和执行参数保持原模型，后续 send、queue 与新子任务继承新选择。结果由 `thread.updated` 或快照确认。

项目按钮支持原生文件夹选择器和手输目录。切换到另一个项目会打开本地新会话并保留草稿；重新选择同一目录不切走当前会话。

新会话的工具权限在“执行设置”中选择：自动执行或执行前确认。确认模式在 bash/write/edit 前询问，子任务继承；等待确认时，工具状态也显示等待确认。Provider 原生 confirm/select/input/editor 请求均可回答，已回应或失效的请求不再重复提交。

## 会话与子任务

每个会话独立保存草稿和阅读位置。上滚暂停跟随，“跳到最新”回到底部；连接恢复不会自动重发用户指令。派出子任务使用当前草稿，Git 子任务默认独立 worktree；可打开子任务、返回父任务、忽略结果和用草稿追问。

默认整组子任务完成后自动续行；启用“确认子任务结果后再继续”则保留明确的确认入口。新续行的输出在事务内加段落分隔，避免把前后回复粘成一个字符串，恢复不会重复加分隔。

草稿、选中会话、主题、快捷键和新会话配置原子保存至私有数据目录的 `desktop-state.json`。未确认客户端命令不跨进程自动重发；已提交的线程、队列、任务、工具、审批及交付状态由 Core 的 SQLite 保存。关闭桌面不会停止独立 worker。

## 验证与限制

真实中文多行提交、键盘边界和原生焦点有自动化测试覆盖；自动化 `setValue` 不替代 macOS 真实输入法候选、预编辑和上屏的人工验收。Linux 原生窗口仍未验收。

已接入内嵌 PTY、附件、本地 Git 分支合并、进程协议插件与 SSH 远程窗口；系统 Terminal 入口继续保留。diff 展示暂存、未暂存和未跟踪状态，冲突合并、hooks/签名失败按实际结果处理。
